## Questions

## Application Structure

The application uses a Flask factory in `app_server.create_app`. Web routes are registered by the application factory. Feature modules handle request workflows and call the generated `persistence` package for storage.

## Module Ownership

| Boundary | Owner | Rule |
|----------|-------|------|
| Application factory | `app_server` | Creates and configures the Flask application. |
| Web routes | Feature modules | Translate HTTP requests into feature operations. |
| Persistence | Generated `persistence` package | Owns database connections, schema operations, and repository calls. |
| Configuration | `app_server` | Resolves application settings and database configuration. |
| Templates and styling | Interface layer | Renders the server-rendered reading-list screen. |
| External services | None | No external services are required. |

## Routes

| Method | Route | Owner |
|--------|-------|-------|
| GET | `/` | `FEATURE-READING-LIST.md` |
| POST | `/books` | `FEATURE-ADD-BOOK.md` and `FEATURE-VALIDATE-BOOK.md` |
| POST | `/books/<book_id>/delete` | `FEATURE-REMOVE-BOOK.md` |

## Technology Stack

| Technology | Use |
|------------|-----|
| Python | Application implementation and tests. |
| Flask | Web application factory, routing, and test client. |
| SQLite | Local relational persistence. |
| pytest | Automated test suite. |
| HTML/CSS | Server-rendered browser interface. |

## Technical Decisions

- The primary page is served at `/`.
- Book creation uses `POST /books`.
- Book removal uses `POST /books/<book_id>/delete`.
- Features access persistence only through generated repository operations.

Intent: The reading-list route presents persisted books in insertion order.

from persistence.testing import committed_session
from app_server.testing import web_client

first_title = "Reading List First"
first_author = "Reading List Author One"
second_title = "Reading List Second"
second_author = "Reading List Author Two"

with committed_session() as db:
    first = db.books.create(
        title=first_title,
        author=first_author,
        insertion_order=900001,
    )
    second = db.books.create(
        title=second_title,
        author=second_author,
        insertion_order=900002,
    )

try:
    client = web_client()
    response = client.get("/")
    assert response.status_code == 200
    body = response.get_data(as_text=True)
    first_position = body.index(first_title)
    second_position = body.index(second_title)
    assert first_position < second_position
finally:
    with committed_session() as db:
        db.books.delete(id=first.id)
        db.books.delete(id=second.id)

| Consumes    | `app_server.create_app`, `persistence.books.delete` |

## Questions

- None.

## Purpose

A reader submits the removal action for a selected book. The feature deletes only that persisted identifier through `books.delete`, then returns to the list workflow.

## Database Interface

- `FEATURE-REMOVE-BOOK-001` — write: delete a book - supplies: `id` - returns: `id`

## Workflow

1. A book identifier is submitted to `POST /books/<book_id>/delete`.
2. The selected book is deleted through the persistence contract.
3. The reader returns to the reading-list page.
4. The next read omits the removed book.

## Programmatic Acceptance

=== AC remove-book-route ===
Intent: The removal route deletes the selected book and returns to the reading-list workflow.

from persistence.testing import committed_session
from app_server.testing import web_client

title = "Remove Book Acceptance Title"
author = "Remove Book Acceptance Author"

with committed_session() as db:
    created = db.books.create(
        title=title,
        author=author,
        insertion_order=900003,
    )

try:
    client = web_client()
    response = client.post(f"/books/{created.id}/delete")
    assert response.status_code == 302

    follow_up = client.get("/")
    assert follow_up.status_code == 200
    body = follow_up.get_data(as_text=True)
    assert title not in body
finally:
    with committed_session() as db:
        db.books.delete(id=created.id)
=== END AC remove-book-route ===

from persistence.testing import committed_session

title = "Remove Book Readback Title"
author = "Remove Book Readback Author"

with committed_session() as db:
    created = db.books.create(
        title=title,
        author=author,
        insertion_order=900004,
