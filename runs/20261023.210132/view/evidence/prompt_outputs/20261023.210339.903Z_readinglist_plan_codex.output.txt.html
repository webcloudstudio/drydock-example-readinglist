# FEATURE: Validate Book

| Field       | Value |
|-------------|-------|
| Version     | 20261023 V1 |
| Description | Validates book submissions and returns correction feedback for incomplete entries. |
| Depends On  | ARCHITECTURE.md, DATABASE.md, FEATURE-ADD-BOOK.md |
| Provides    | validation for POST /books |
| Consumes    | POST /books, app_server.create_app, persistence.books.list |

## Questions

- None.

## Purpose

The validation boundary protects the reading list from incomplete books. Submissions with an empty title, empty author, or both are rejected before persistence with a client-error response. The form remains usable so the reader can correct and resubmit.

## Workflow

1. Receive title and author form values at `POST /books`.
2. Reject the submission with HTTP 400 when either required value is empty.
3. Preserve the submitted values and identify the missing field or fields in the rendered feedback.
4. Do not create a persistence record for rejected input.
5. Accept corrected values through the existing add-book workflow.

## Database Interface

- `FEATURE-ADD-BOOK-001` — write: create a book - supplies: `title`, `author`, `insertion_order` - returns: `id`, `title`, `author`, `insertion_order`
- `FEATURE-READING-LIST-001` — read: list books - supplies: — - returns: `id`, `title`, `author`, `insertion_order`

## Layout

- A form with accessible title and author inputs and a submit control.

from app_server.testing import web_client

title = "Screen Removal Title"
author = "Screen Removal Author"

client = web_client()
create_response = client.post("/books", data={"title": title, "author": author})
assert create_response.status_code == 302

before_response = client.get("/")
assert before_response.status_code == 200
before_body = before_response.get_data(as_text=True)
assert title in before_body
assert author in before_body

from persistence.testing import db_session

with db_session() as db:
    rows = db.books.list()
    selected = next(row for row in rows if row.title == title and row.author == author)
    book_id = selected.id

delete_response = client.post(f"/books/{book_id}/delete")
assert delete_response.status_code == 302

after_response = client.get("/")
assert after_response.status_code == 200
after_body = after_response.get_data(as_text=True)
assert title not in after_body
assert author not in after_body
