Purpose

ReadingList is a single-reader web application. A reader adds a book with a title and author, views books in the order added, and removes books. Empty titles or authors are rejected with a clear error. The application ships automated tests and a POSIX bin/test.sh.

Layering

Routes call services; services call db.<table>.<verb>(...). SQL, sessions, table names, and column names never cross the persistence boundary. Books are always returned ordered by id ascending, which is the order added.

Technical Decisions

  • Test runner command is pytest -q from the application root.
  • Rejected input returns 400; removal of an unknown book returns 404 (see DECISIONS.json).
  • Server-rendered forms provide the user interface; JSON routes share the same services.
