FEATURE: List Books Tests

FieldValue
Version20261023 V1
DescriptionAutomated pytest tests that prove books are listed in the order they were added.
Depends OnFEATURE-ListBooks.md
ProvidesNone
ConsumesGET /books

Purpose

Guarantee that listing books in the order added is covered by an automated test that runs under pytest -q.

Deliverable

tests/test_list_books.py, using the web_client fixture from tests/conftest.py. The file contains pytest tests covering at least:

  • an empty store returns an empty JSON array from GET /books (the test isolates its own data from any residue);
  • a single added book is returned with id, title, and author;
  • several books added in sequence are returned in the order added, with ascending ids.

Each test uses unique titles and removes the books it created.

Reads

GET /books.

Writes

POST /books, as test setup only.

Database Interface

  • None — persistence is owned by FEATURE-ListBooks.md.

Intent: Books added in sequence are returned by GET /books in the order added.
Suite: scoped

from app_server.testing import web_client from persistence.testing import committed_session

author = "ListTestsOrderAuthor" titles = ["ListTestsFirst", "ListTestsSecond", "ListTestsThird"]

def purge(): with committed_session() as db: for row in db.books.list(): if row.author == author: db.books.delete(id=row.id)

client = web_client() purge() try: for t in titles: assert client.post("/books", data={"title": t, "author": author}).status_code == 303 rows = [r for r in client.get("/books").get_json() if r["author"] == author] assert [r["title"] for r in rows] == titles ids = [r["id"] for r in rows] assert ids == sorted(ids) finally: purge() === END AC list-order-behavior ===
