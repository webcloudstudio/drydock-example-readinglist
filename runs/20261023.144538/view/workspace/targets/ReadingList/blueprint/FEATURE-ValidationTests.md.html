FEATURE: Validation Tests

FieldValue
Version20261023 V1
DescriptionAutomated pytest tests that prove an empty or whitespace-only title or author is rejected with status 400, a reported reason, and nothing stored.
Depends OnFEATURE-RejectEmptyTitle.md, FEATURE-RejectEmptyAuthor.md, FEATURE-AddBook.md, ARCHITECTURE.md
Providestests/test_validation.py
ConsumesPOST /books, GET /books

Purpose

The guardrails "Never accept an empty title or an empty author" and "Never omit a rejection reason when a submission is rejected" require automated coverage. This specification governs the project's own pytest module tests/test_validation.py, written by the build agent beside the finished code. It exercises validation only through POST /books and GET /books.

Database Interface

  • None — persistence is owned by FEATURE-AddBook.md.

Test Module

tests/test_validation.py uses the web_client fixture and covers one behavior per test:

BehaviorExpectation
Empty title rejectedStatus 400, a non-empty error, and field naming the title.
Whitespace-only title rejectedSame as an empty title.
Missing title rejectedSame as an empty title.
Empty author rejectedStatus 400, a non-empty error, and field naming the author.
Whitespace-only author rejectedSame as an empty author.
Missing author rejectedSame as an empty author.
Nothing stored on rejectionThe list from GET /books is unchanged after a rejected submission.
Browser rejection shows reasonWithout Accept: application/json the answer is 400 and the page body is non-empty.

import subprocess import sys from pathlib import Path

import app_server

module = Path("tests/test_validation.py") assert module.is_file() result = subprocess.run( [sys.executable, "-m", "pytest", "-q", str(module)], capture_output=True, text=True, ) print(result.stdout) print(result.stderr, file=sys.stderr) assert result.returncode == 0 === END AC validation-tests-module-passes ===

=== AC validation-empty-title-rejected ===
Intent: An empty title is rejected with 400, a non-empty reason, the title field named, and nothing stored.

from app_server.testing import web_client

client = web_client() field = "title" other = "author" before = client.get("/books").get_json() response = client.post( "/books", data={field: "", other: "Valid Author"}, headers={"Accept": "application/json"}, ) assert response.status_code == 400 body = response.get_json() assert isinstance(body["error"], str) and body["error"].strip() assert body["field"] == field assert client.get("/books").get_json() == before === END AC validation-empty-title-rejected ===

Guardrails
