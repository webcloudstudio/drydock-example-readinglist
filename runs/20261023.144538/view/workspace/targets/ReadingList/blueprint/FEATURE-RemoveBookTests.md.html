FEATURE: Remove Book Tests

FieldValue
Version20261023 V1
DescriptionAutomated pytest tests that prove removing a book omits it on the next read, preserves the order of the rest, and answers 404 for an unknown id.
Depends OnFEATURE-RemoveBook.md, FEATURE-AddBook.md, FEATURE-ListBooks.md, ARCHITECTURE.md
Providestests/test_remove_book.py
ConsumesPOST /books/{id}/delete, POST /books, GET /books

Purpose

The Reading List guardrail "Never ship a behavior without an automated test covering it" applies to removal. This specification governs the project's own pytest module tests/test_remove_book.py, written by the build agent beside the finished code against observed output. It exercises removal only through the public HTTP interface.

Database Interface

  • None — persistence is owned by FEATURE-RemoveBook.md.

Test Module

tests/test_remove_book.py uses the web_client fixture from tests/conftest.py and covers one behavior per test, each named for the behavior:

BehaviorExpectation
Removed book is omittedAfter POST /books/{id}/delete answers 303, GET /books no longer lists that id.
Other books remainRemoving one of several books leaves the others listed.
Remaining order preservedThe remaining books keep their relative order of addition.
Unknown idPOST /books/{id}/delete for an id that does not exist answers 404.
Repeat removalRemoving the same id twice answers 303 then 404.

Each test creates the books it needs through POST /books, reads ids back from GET /books, and removes the books it created before finishing, so tests do not depend on each other's residue.
